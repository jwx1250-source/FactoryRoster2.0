# Guide distribution plan

This is an editorial distribution plan for the ten highest-intent published guides. It does not create a public social route or schedule an automated job.

| Timing | Action |
| --- | --- |
| Day 0 | Publish the guide, share the X and LinkedIn pack, and answer one relevant community question with the guide as context. |
| Day 1 | Share one carousel or checklist excerpt and link back with the guide UTM. |
| Day 3 | Publish a practical example or mistake to avoid; respond to comments with the canonical guide. |
| Day 5 | Share the Reddit discussion angle only where it is genuinely useful and allowed by community rules. |
| Day 10 | Re-share the strongest unanswered question with a new opening line. |
| Day 21 | Review clicks and assisted search activity, then keep, revise, or retire the pack. |

Use `utm_source` values `x`, `linkedin`, or `reddit`, with `utm_medium=social` and `utm_campaign=guide_distribution`. UTM parameters are attribution only and do not change canonical URLs.

The ten packs are defined in `lib/guide-distribution.ts`: verification checklist, scam red flags, RFQ writing, MOQ, MOQ negotiation, golden samples, pre-shipment inspection, Incoterms, import duties, and Canton Fair basics.
